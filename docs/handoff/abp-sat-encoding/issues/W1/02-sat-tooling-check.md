# 02: Kiểm chứng tooling (`docs/sat_tooling.md`)

**Tuần:** W1 · **Owner:** P2 (Quang) · **Status:** ready-for-human

**What to build:** Ghi kết luận thực tế về PySAT và Kissat trên máy dev. Không dựa vào trí nhớ.

**Blocked by:** None (can start immediately)

- [ ] Ghi PySAT version, backend interface, cách lấy model, hành vi timeout.
- [ ] Ghi assumptions/incremental support (Kissat không incremental).
- [ ] Liệt kê AMO encoder có sẵn trong PySAT (pairwise, seqcounter...).
- [ ] Ghi cách gọi Kissat: qua PySAT hay binary ngoài; cách đo t_encode / t_solve / memory khác nhau thế nào.
- [ ] Kissat chỉ cần có kết luận; không bắt buộc chạy xong W1.
